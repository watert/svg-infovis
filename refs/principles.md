# 设计意图与第一性原则

> 这篇回答**为什么**, 不回答是什么。分层与边界的现状 → `refs/layering.md`;
> 纪律全表(可执行的那份)→ `../SKILL.md`; 数字只在一处 → `../QUICKREF.md`。
> 写作纪律: 下面每条断言都必须能落到**一个实跑事故**或**一次实测**上。
> 落不上的不是原则, 是偏好 —— 偏好写进 code review, 不写进原则。

## 命题

**几何是纪律, 意图是作者的。**

一句话拆开是两半: 凡是能算的, 交给能算的、可复算的、可审的代码; 凡是关于"要表达什么"的,
一个字都不许猜。门禁不是替作者做设计, 是**在出厂前把作者没注意到的物理冲突喊出来**。
所以本仓最贵的资产不是那十九项门禁, 是"作者写歪了却没人喊"这件事被消灭的机制。

立项时 8 张真实 Mermaid 结构图上的实测支撑了这条命题: 纯几何门禁只喊 3 声(召回 ≈ 21%),
而肉眼每图 1–2 处想改(分层被排成阶梯 / 组内空白 41–80% / 长边横扫)。
**疼在意图表达与排布旋钮, 不在像素精度。** 于是本仓不做自动排布、不做比例尺, 只把旋钮做显式。

## 原则表

### P1 · 能焊进代码的, 不要留在文档散文里

- **断言**: 判据必须变成控制流。`exportScene` 拒出图(想强出得显式 `force`, 产物打 `data-draft`),
  而不是 README 里写一句"请注意不要重叠"。
- **代价**: prompt 是软约束, agent 必违规 —— 散文纪律的存活率是 0。所以我们接受"作者必须显式写一行
  `force` 才能违规"这种别扭, 而不接受文档里"请务必"三个字。
- **事故**: 早期版本靠文档约束版式, 门禁形同虚设; 现在的 `audit` 是同一件事的另一半。

### P2 · core 不猜意图

- **断言**: 不自动 rank、不自动避障、不自动分组、不自动换行。`via` 是作者声明的折点不是避障;
  `assignLanes` 不显式调用就完全不发生分配; `nudge` 只动坐标不动拓扑。
- **代价**: 作者要自己想明白拓扑, 手上没有"一键整理"。
- **对比**: 本仓与模板库(AntV 那种 93 个模板的打法)是两条路。自动层一旦进来, 几何纪律就退化成
  建议 —— 而"建议"在交付压力下必然被忽略, 那时唯一值钱的门禁也就跟着失效了。

### P3 · 字节确定

- **断言**: 禁 `Date.now` / `Math.random`; 几何数过 `round1`; 集合按 codepoint 序;
  属性键按 codepoint 序; 同输入 → 逐字节相同输出。产物进 git 可以肉眼对账。
- **代价**: 做不了"生成时间戳"、做不了"每次不一样的随机抖动"这类小恩小惠。
- **收益**: `refs/*.svg` 与 `assets/hero.svg` 变成可回归的断言物 —— 改内核时"输出是否变了"一眼可判
  (hero 有 `test/hero-svg.test.ts` 的字节等式守着; 示例产物全量回归走 website prerender 的 SVG 文本 diff)。

### P4 · 一处事实一处

- **断言**: 每个数字、每条公式只有一份权威(字号在 `NODE_TEXT_LAYOUT`, 度量在 `measureText`,
  盒并集在 `geometry/box`, 门禁码在 `knives/codes`); 文档同理, 缺省值只写进 `QUICKREF.md` 缺省值表。
- **代价**: 写文档时要克制, "顺手在这也提一句"就是制造第二权威。
- **事故**: 过去 demo 侧**手抄了 23 个门禁码**并在注释里写"core 至今没有导出码注册表", 手抄清单必然
  与真值漂开 —— 覆盖表的信用一破, 它报的"全绿"全是假证据。现在有注册表, 且判据在
  `test/codes-registry.test.ts`: 三把刀实际产出的码集合 ⊆ 注册表。

### P5 · 渲染面必须是 scene 的满射

- **断言**: 出图走 `sceneChildren`; 文本包围盒走 `measureText` / `textFit` 而非手估; 组框标题走
  `groupLabelRect` 与 `groupShape` 同源。
- **代价**: 建图代码略啰嗦(节点表要同时喂渲染与审计)。
- **事故**: 手估宽度会让 audit 量错净空 —— **门禁本身就是错的, 比没有门禁更糟**。
  差集(有位置无内容 / 有内容无位置)落在 `phantom_labels` / `phantom_texts` 里, 不许静默。

### P6 · 渲染自己算, 不借渲染器的力

- **断言**: 不用 `dominant-baseline`(走 `baselineY`)、不用 SVG `marker` 箭头、垂直居中看行中心
  (`central = 行心 + 0.35em` 纯公式)。描边居中, 外扩 `strokeWidth/2`; viewBox 不写死。
- **代价**: 几行手算换"产物在任意渲染器里长一样"。
- **事故**: 曾有一个 `OPTICAL_CENTRAL_FIX` 全局补偿(单行文字统一下沉 1.2px), 最后**被删掉** ——
  局部补丁在换字号/换行数后会漂。实测 CJK 墨心在 0.3555–0.3594em, 残差 ≤0.1px, 纯公式够用。
  教训: **别在渲染层加全局 px 补偿**。

### P7 · 新门禁自己举证

- **断言**: 加判据要给出两个方向的反例, 外加"把每个豁免条件单独松掉"的变异测试;
  启发式一律 warning; 每个新判据必须写明**作者用哪个旋钮修** —— 没有旋钮的报错不立项。
- **代价**: 慢。一个判据的论证成本远高于它的实现成本(`stat.ts` 344 行、`progress.ts` 491 行,
  而"每件 ~100 行内"的估算被低估约 3 倍; 磨合成本在契约细节: 幂等 / 读数盒 / tone 接线)。
- **推论**: 美学度量**攒够 ≥3 张真实图的踩坑样本**才谈把警告升级为判据。现在启发式一律 warning,
  这不是laziness, 是举证责任。

### P8 · 盒子是墨迹的, 留白是作者的

- **断言**: `bounds` 一律不加内边距; 盒外的距离归 `pack` 的 `gap` / 列距, 归块与块的 `place`。
- **事故**: 进度条把盒高当旋钮(`h` 被块内尺寸吃掉), 摊回声明时静默喂进去, 画出一根 36 高的条
  **而没有人喊**。故: 盒高是推导结果, 块内的尺寸旋钮不许占用 `h`(`progressBlock` 的条高因此叫 `barH`)。

## 三条口吻的代价(诚实版)

| 口吻 | 换来 | 付出 |
|---|---|---|
| 零运行时依赖 | 大目录云同步环境里不与版本库抢构建产物; 装完即用 | 素材链(图标)只能构建期读盘; 没有生态现成的图表能力, 真图表得走 `embed` |
| 字节确定性 | 产物可对账、可回归 | 失去时间戳与随机微扰这类"小功能" |
| 一处事实一处 | 改一处不会漏改三处 | 写文档时必须忍住"顺手再提一句" |

## 原则冲突时怎么裁

原则不是宪法, 是当前权衡的定格。真撞上了按这三条裁, 顺序即优先级:

1. **P1 > P2**。要"更智能"之前先问能不能把新约束焊进控制流。能, 就不是权衡, 是补齐。
   (例: 自动换行的风险不在算法在契约 —— `fit` 反算盒宽依赖行数、行数依赖盒宽, 互相咬。
   没答案前不动 `fit` 契约, 而不是"先实现再调"。)
2. **可检验的 > 优雅的**。判据要能举反例; 抽象要能被第二个消费者证伪。
   `geometry/` 的"≥2 消费者才上提"与 `blocks/` 的"别急着立宪法"是同一条规则的两次应用:
   **层还在长时, 少立公共点; 公共点一旦立错, 全仓跟着改。**
3. **拿不准就退回更笨的选项**。解析外来素材 fail-closed 还是容错跳过? 本仓选 fail-closed ——
   静默跳过会画出少几笔的图标, 那是**看起来成功的失败**。

## 什么时候该推翻某条原则

写下退出条件, 别让它变成新的教条 —— 每条都有一个该被它自己淘汰的场景:

- **P2(不猜意图)** 的退出条件: 当"作者声明"的成本高到让门禁形同虚设(比如 20 个节点以上的手写拓扑
  已经到人脑极限), 就该考虑把"声明"降级成"描述意图 + 解算"。届时的判据是**新解算层必须落在 core 之外**。
- **P3(字节确定)** 的退出条件: 引入随机抖动(手绘风 / 抗锯齿抖动)或时间戳水印的那天。抗辩:
  那属于出图工具, 不属于几何内核。
- **P7(举证成本)** 的退出条件: 门禁的假阳性成本超过漏报(比如密度类启发式长期被作者用 `# 豁免` 绕过)。
  那时的正确反应是**删掉它**, 不是给它降档。
